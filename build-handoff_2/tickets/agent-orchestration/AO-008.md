# AO-008：外部 adapter timeout 與錯誤停止

- **目標**：安全處理 Planner／Evaluator／Critic 的 timeout、schema 與服務錯誤。
- **背景**：正式 Demo 失效時不能默默切換 Mock。
- **前置條件**：各 adapter 的 timeout 與錯誤型別。
- **實作範圍**：停止 adaptation、保留最後 Snapshot、錯誤事件、重試提示與明確 offline Mock mode。
- **涉及介面或檔案**：adapter boundary、controller error state、UI status。
- **驗收條件**：錯誤不改 policy；Snapshot 與錯誤原因可讀取。
- **測試要求**：timeout、schema error、服務錯誤、offline Mock 標籤。
- **依賴 ticket**：AO-001。
- **完成定義**：沒有 silent fallback，錯誤行為可重現。
