# AO-001：建立 adaptation state machine 與 trigger

- **目標**：建立單一 adaptation lifecycle 與 trigger 去重。
- **背景**：同一 run 不能並行啟用多個 policy。
- **前置條件**：可讀取 Snapshot 與 `run_id`／`snapshot_version`。
- **實作範圍**：定義狀態、轉移、adaptation ID、trigger 判斷與重複事件處理。
- **涉及介面或檔案**：orchestration controller、shared contract、事件模型。
- **驗收條件**：trigger 成立才進入流程；相同 run window 的重複 trigger 不會並行。
- **測試要求**：未觸發、重複觸發、跨 run 觸發。
- **依賴 ticket**：無。
- **完成定義**：狀態與事件可由測試讀取，錯誤轉 `failed`。
