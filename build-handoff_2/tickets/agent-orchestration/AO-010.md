# AO-010：Agent orchestration integration tests

- **目標**：以整合測試驗證完整 adaptation 閉環。
- **背景**：單元測試通過不代表既有 Skill reuse、Candidate 迭代與啟用能串起來。
- **前置條件**：AO-001 至 AO-009 的可測試介面。
- **實作範圍**：建立 deterministic fake adapters，覆蓋 reuse、五版失敗、Candidate 通過、錯誤停止與 mode 行為。
- **涉及介面或檔案**：`tests/`、orchestration controller、fake adapters。
- **驗收條件**：所有驗收情境可自動執行，sandbox 不改 live Run，running job 不被中斷。
- **測試要求**：固定 seed／run/version 重現、事件序列與 metrics attribution。
- **依賴 ticket**：AO-001 至 AO-009。
- **完成定義**：測試在 `uv run pytest` 下通過且失敗訊息可定位。
