# AO-003：Candidate 版本與 Planner／Critic 迭代

- **目標**：建立 Candidate 版本鏈與 feedback 迭代。
- **背景**：只有既有 Skills 全部失敗才可產生新 Candidate。
- **前置條件**：AO-002 結果與 Planner／Critic adapter。
- **實作範圍**：`hybrid-v1` 至 `hybrid-v5`、parent ID、原因、feedback 與版本狀態。
- **涉及介面或檔案**：`propose_candidate`、Candidate record、adaptation state。
- **驗收條件**：失敗 Candidate 產生下一版且 metadata 完整；不得跳過既有 Skill evaluation。
- **測試要求**：v1→v2、parent chain、重複 ID 防護。
- **依賴 ticket**：AO-002。
- **完成定義**：每版可追蹤並可交給 Evaluator。
