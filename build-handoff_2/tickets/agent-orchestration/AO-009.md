# AO-009：事件、metrics attribution 與 UI 狀態整合

- **目標**：把 adaptation 證據提供給 UI 並分離 metrics 層級。
- **背景**：live、segment、sandbox 結果不可混淆。
- **前置條件**：AO-005、AO-006、UI snapshot schema。
- **實作範圍**：adaptation events、candidate feedback、policy segments、來源與 stage 顯示。
- **涉及介面或檔案**：Snapshot、events、Metrics & Code、Skill Library。
- **驗收條件**：UI 顯示 reuse／candidate／registration／activation 的完整歷程。
- **測試要求**：事件順序、run/version 關聯、四類 metrics 分離。
- **依賴 ticket**：AO-006、AO-007、AO-008。
- **完成定義**：同一 Snapshot 的 UI、事件與 metrics 可互相對應。
