# AO-002：既有 Skill evaluation 與最佳選擇

- **目標**：先評估所有已驗證 Skills 並依固定順序選擇。
- **背景**：既有 Skill 有效時不得建立 Candidate。
- **前置條件**：Evaluator adapter 與 Skill Library 可列出 verified Skills。
- **實作範圍**：相同 workload／seed／state／window 的評估、結果收集、排序。
- **涉及介面或檔案**：`evaluate_existing_skills`、`select_existing_skill`。
- **驗收條件**：目前 Skill 通過時維持；多個通過時依 expired、completed、P95、目前 policy、ID 選擇。
- **測試要求**：目前通過、其他通過、多重平手、全部失敗。
- **依賴 ticket**：AO-001。
- **完成定義**：通過時不呼叫 Planner 且產生 reuse 結果。
