# AO-005：Skill registration 與 automatic activation

- **目標**：讓通過的 Candidate 自動成為 Skill 並啟用。
- **背景**：Demo 不需要 User accept。
- **前置條件**：AO-004、Skill Library adapter。
- **實作範圍**：註冊 metadata、`skill_registered`、`policy_activated`、current policy 更新。
- **涉及介面或檔案**：`register_skill`、`activate_skill`、Skill Library。
- **驗收條件**：只有通過者可註冊；啟用原因與版本可查詢。
- **測試要求**：通過註冊、失敗不註冊、重複 ID。
- **依賴 ticket**：AO-004。
- **完成定義**：Skill Library 與 Snapshot 顯示相同 active policy。
