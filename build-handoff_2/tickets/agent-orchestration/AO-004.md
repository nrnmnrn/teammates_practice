# AO-004：Evaluator gate 與五版上限

- **目標**：統一既有 Skill 與 Candidate 的 gate 結果處理。
- **背景**：指標改善與契約驗證必須同時成立。
- **前置條件**：Evaluator result schema、AO-003。
- **實作範圍**：expired／completed／P95 比較、contract validation、sandbox status、失敗 feedback。
- **涉及介面或檔案**：`evaluate_candidate`、gate evaluator、EvaluationResult。
- **驗收條件**：通過可註冊；失敗可回饋；最多 5 版，全部失敗維持原 policy。
- **測試要求**：指標退化、契約錯誤、執行錯誤、第五版與第六版阻擋。
- **依賴 ticket**：AO-003。
- **完成定義**：所有 gate 結果可序列化並帶原因。
