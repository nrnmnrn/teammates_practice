# 排程輸送帶領域詞彙

本表統一產品用詞。規則與驗收以 [PRD](PRD.md) 為準；程式責任見 [ARCHITECTURE](ARCHITECTURE.md)。

## Language

**Job（訂單）**：
一筆具有到達時間、工時、優先度及完成期限的排程工作；母 PRD 的 Request 指同一物件。
_Avoid_: 把 Request 與 Job 當成兩種訂單、開發用 Ticket

**Arrival（到達時間）**：
訂單進入可等待佇列的模擬時間。
_Avoid_: 建立文件的時間、電腦時鐘

**Processing time（工時）**：
Worker 完成一筆訂單所需的已知模擬秒數。
_Avoid_: 運輸時間、畫面播放秒數

**Deadline（完成期限）**：
訂單最晚必須完成的絕對模擬時間。
_Avoid_: 剩餘秒數、必須開始的時間

**Priority（優先度）**：
訂單的優先程度，數值越大代表越優先。
_Avoid_: 越小越優先、畫面列順序

**Worker（處理者）**：
本產品唯一的訂單處理者，一次處理一筆且不中途搶占。
_Avoid_: 開發隊員、AI 子代理

**Policy（排程策略）**：
從可準時完成的等待訂單中選出下一筆工作的規則。
_Avoid_: 畫面排序、已證實改善的策略

**Skill（產品技能）**：
技能庫中的一個可用 Policy，以及該策略的說明、來源與使用紀錄。
_Avoid_: 開發工具的 SKILL.md、每次點擊套用

**Run（一局）**：
從初始化或重設起，至下一次重設前的模擬範圍。
_Avoid_: 一次 agent session、單次畫面更新

**Snapshot（狀態快照）**：
同一模擬時刻的訂單、Worker、策略、事件及累計結果的一致描述。
_Avoid_: 螢幕截圖、不同時刻資料的拼接

**Mock 候選（預寫示範候選）**：
可提出、接受或拒絕的單一預寫 Hybrid 策略。
_Avoid_: 真實 AI 生成、已通過評估、已證實改善

**本局累計指標**：
目前 Run 自開始至觀察時間的完成、逾期、吞吐量及完成延遲統計。
_Avoid_: 新策略獨立成效、滑動視窗平均
