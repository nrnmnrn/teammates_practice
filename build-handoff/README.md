# 實作交接包

此資料夾是規劃 repo 與比賽實作 repo 的唯一文件介面。實作只需取得本交接包；唯一自足的實作規格是 [PRD.md](PRD.md)。使用者已選定根目錄 `Hackathon_PRD.md` 為規劃來源，並授權本次文件同步；PRD 記錄來源 SHA-256 與 capture 日期，勿另行猜測或帶入研究筆記。

本包描述一個 Gradio 排程展示：三個 tabs、五種固定策略、真實排程與指標，以及 Mock（預寫示範，不是真實 AI）候選流程。隊友後端是完整交付的必要條件；本機模擬器只可在明確選擇 `local` 時作開發或備援展示，不算完成。`team` 後端無法載入時必須明確失敗，不得靜默改用本機資料。

目前僅有「咏宸已完成 UI」的使用者回報，尚未技術驗證。版本、後端契約、測試、瀏覽器驗收及展示演練皆仍待證據。除已選定的來源與本次文件同步外，其他產品決策仍暫停，等待主辦方回覆題目變更請求；本文不把任何賽事規則當作已確認。

9/10 候選整理、9/11 演練、9/12 開賽後建立實作 repo 與單向匯出的日期均為規劃中、未確認；團隊凍結前不得視為正式可複製版本。

## 必要內容

- `PRD.md`：唯一自足的產品規格，含來源／版本、產品邊界、後端契約、驗收與已知限制。
- `checklist.md`：實作前、演練、證據與凍結檢核。

README、`CONTEXT.md`、後端串接文件與 UI 操作教學是實作交付物；它們在實作 repo 內建立，不是額外的規劃交接文件或 PRD 前置條件。交接包不含隊友原始碼、研究全文、會議紀錄、長篇教學、個人資料、secrets，或任何賽前可直接用於參賽作品的程式碼。

## 使用界線

- 開賽後才由此包建立實作 repo；不得在規劃 repo 輸出或累積參賽程式碼。
- 每位參與者使用自己的憑證；共享 GPU 不代表可共享憑證。
- 實作完成需驗證 `team` 後端，不得以 `local` 結果冒充隊友後端結果。
- 主辦方回覆前，不新增產品決策或推定賽事規則。
