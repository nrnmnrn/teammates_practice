# 實作交接包

這個資料夾是規劃 repo 與比賽實作 repo 之間唯一的文件介面。9/10 形成候選版本，9/11 全流程演練通過後才凍結；9/12 開賽後單向複製一次。

## 應包含

- `AGENTS.md`：coding agent 必須遵守的短規則。
- `CONTEXT.md`：只含產品實作需要的共同名詞。
- `PRODUCT-SPEC.md`：問題、使用者、核心流程、需求與不做範圍。
- `ACCEPTANCE.md`：可執行或可觀察的驗收條件。
- `WORKFLOW.md`：實作 repo 的分支、測試、review 及常用命令。
- `SKILLS.md`：精簡 skill 清單、用途與凍結來源 commit。
- `RUNBOOK.md`：啟動、停止、demo 與降級步驟。

## 不應包含

- 歷屆得獎研究全文。
- 比賽新聞、宣傳資料或長篇規則摘錄。
- 會議逐字稿與討論歷史。
- 新手教學全文。
- 被否決的產品構想。
- secrets 或個人資料。
- 任何賽前完成、可直接用於參賽作品的程式碼。

目前只建立清單，不填入未獲主辦方確認的產品設計。
