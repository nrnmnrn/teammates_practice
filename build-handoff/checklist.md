# 實作交接包追蹤清單

母 [PRD](PRD.md) 定義唯一產品規則；[ACCEPTANCE](ACCEPTANCE.md) 保留完整驗收案例。本包所有實作**未驗證**。具體子 PRD、owner、工作順序、相依與追蹤方式待團隊決定；此處不預先建立手填追蹤欄。

狀態可用：**未驗證**、**進行中**、**待共同確認**、**通過**、**blocked**。必要案例失敗不可通過。GitHub 證據連結可記錄，不必重複身份或日期。

## 紀錄規則

- 前置合併、`main` 驗證前不可開工；同檔修改先協調。例外並行須于喬明確同意並在 GitHub 留證據。
- 作者自查加至少另一人共同確認，不等於 merge 授權；授權 merge 與 `main` 驗證後才完成。
- 修改後重驗受影響案例與串接；最終展示前重跑完整主流程。附件、截圖、影音可選。
- CPU 為執行基準；歷史 A6000 教材非本產品準備或驗收要求，不能宣稱效能已測。
- 演練 repo 不產生競賽碼；實作 repo 僅在開賽後建立。規格版本使用驗證／凍結的 canonical Git commit；遷移前雜湊不是現行版本。
