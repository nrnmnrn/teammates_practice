母 [PRD](PRD.md) 定義唯一產品規則；[ACCEPTANCE](ACCEPTANCE.md) 定義子 PRD、相依、案例與共同確認。所有實作目前均為**未驗證**。本次 PRD 規格決定已獲使用者授權，但尚未全隊共同確認、凍結或驗證。

狀態僅用：**未驗證**、**進行中**、**待共同確認**、**通過**。案例不各設勾選或批准。作者自驗後記「待共同確認」；實測符合預期、至少另一隊員共同確認、審查通過且整份合併後，才記「通過」。

規格版本：驗證／凍結時使用的 canonical Git commit，待填。`088ae4cdf7c9f6cbb439a70630bfff60c49d09d9` 僅為遷移前歷史來源，非現行規格版本。

## 紀錄規則

- 未認領工作可自行登記；已有處理者時先協調。同檔多人修改亦先協調。
- 必要案例失敗時，子 PRD 與整體均不得標示通過；不可因趕工跳過案例或自行縮範圍。
- 修改後重驗受影響案例與串接；最終展示前重跑完整主流程。
- 證據可為命令輸出、現場觀察或團隊選定附件；不強制截圖或影音。
- CPU 為執行基準。歷史 A6000 教材可保留，但不是本產品準備或驗收要求，也不宣稱效能已測。
- 演練 repo 不產生競賽碼；開賽後的實作 repo 才接收交接包。
