# Codex 實務經驗

本頁收錄 owner 已核可、可供團隊參考的 Codex 使用做法。它們不是官方比賽規則，也不保證在所有 repo、模型或網路環境下都成功。

## 寫入流程

1. owner 提供經驗：情境、做法、結果或限制。
2. Codex 檢查相關 skill 說明、現有手冊與可驗證來源，找出衝突、適用範圍及限制。
3. 無法確認的內容標為「待驗證」；通過檢查的內容標為「已核可操作指引」。
4. 在不包含 secrets 或私人訊息的前提下，將核可內容寫入本頁或適合的既有手冊。

## 貢獻格式

```md
### 做法名稱

- 狀態：待驗證／已核可操作指引
- 情境：什麼任務、repo 狀態或限制下適用。
- 做法：可重現的步驟或 prompt 原則。
- 結果：預期看到什麼；如何判斷有沒有成功。
- 限制：何時不適用、已知風險或替代作法。
- 檢查依據：相關 skill、文件或實際驗證紀錄。
```

## 已核可操作指引

尚無項目。owner 提供第一則經驗並完成檢查後再加入。

## 待驗證做法

尚無項目。
